# Contributing

Merge through a `train/<n>` pull request: `train gate` must be required in branch protection. Ordinary PRs run `pr fast` (cached install, lint, typecheck, build, CLI smoke, and the docs checks) and `pr affected` (tests affected by the diff, in 8 slices that start when `pr fast` is green, reported only; it compares with the PR's own base branch, skips a draft PR and runs when the PR leaves draft; a change of base runs `pr affected (retarget)` from `pr-affected-retarget.yml`); train PRs and main pushes retain the full Node 22/24, Python 3.11/3.12, viewer, replay, leak guard, and validator checks. A newer push to a pull request cancels the older run of that pull request, train pull requests included, so only the latest head of a train can merge; the release pull request is never cancelled. The build shards upload the parts of the emission mutation enumeration, and the job `emission manifest` pools them. `pr fast` is the merge-train entry check, takes about three minutes and has a ten-minute timeout; `pr affected` has a 45-minute timeout, is not required and is not an input of `train gate`. The `ci` and `validators` workflows also accept a manual dispatch with a `jobs` input (comma-separated job ids, no spaces). A dispatch runs only the listed jobs, and only on a `train/*` branch; on `main` it runs nothing and `train gate` fails, so a partial run never stands in for the full suite. On an ordinary PR the `ci` job is named `train gate (ordinary PR)` and passes, and a commit status named `train gate` stays pending with the text "waits for the merge train": the check is yellow, never red, and a required `train gate` cannot pass on a head that is not `train/*`. `train gate` waits for every heavy `ci` job and fails when one failed or was cancelled; a skipped job does not fail it. The `validators` jobs are checked by `train.sh`, which merges a train only when both workflows' runs on its exact head are green.

Cursor Bugbot gives a first-pass review of each pull request (rules in `.cursor/BUGBOT.md`, settings in `.cursor/config/bugbot.yaml`). The independent review is still required; Bugbot does not replace it.
