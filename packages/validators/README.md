# @agent-nexus/driftbench-validators

Validators that prove driftbench works: each plants a known truth, runs one part of the framework and scores a ladder of levels.

Part of [driftbench](https://github.com/NexusGPT/driftbench), block-level evaluation for AI agents: every exchange is a unit test with a Given, a When and a Then.

## Install

```sh
npm install @agent-nexus/driftbench-validators
```

Node.js 22.13 or newer. ESM only, with TypeScript types.

## What is inside

* `defineLadder`
* `measureHardness`
* `readJournal`
* `checkFloors`

The full list of exports is in the type declarations (`dist/index.d.ts`).
