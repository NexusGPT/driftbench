# @agent-nexus/driftbench-adapters

The adapters that connect driftbench to the agent under test: function, http, process, nexus and agent SDKs, with the contract suite every adapter passes.

Part of [driftbench](https://github.com/achammah/driftbench), block-level evaluation for AI agents: every exchange is a unit test with a Given, a When and a Then.

## Install

```sh
npm install @agent-nexus/driftbench-adapters
```

Node.js 22 or newer. ESM only, with TypeScript types.

## What is inside

* `functionAdapter`
* `httpAdapter`
* `processAdapter`
* `nexusAdapter`
* `openaiAgentsAdapter`
* `anthropicAdapter`
* `googleAdapter`
* `langgraphAdapter`
* `replayAdapter`

The full list of exports is in the type declarations (`dist/index.d.ts`).
