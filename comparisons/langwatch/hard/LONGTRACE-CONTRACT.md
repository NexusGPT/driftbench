Build 120 fictional cases from construction, with exactly two independently
labelled criteria per case. Primary truth has 40 pass, 40 fail, 40 inconclusive;
secondary receipt truth has 60 pass and 60 fail. Use at least eight distinct
primary families, including exact entity/value binding, units, action order,
tool error versus completion, conditional promise versus action, sparse trace,
multilingual evidence and strict thresholds. Every record conforms to the
existing JudgeCase shape: id, kind, scenario, criteria[], transcript, truth[].
Additional scoring-only fields are permitted but never enter prompts.

The deciding primary evidence is early: before at least 75 percent of visible
transcript text. Trace length is 12,000 to 24,000 characters, with at least six
named tool calls and diverse later irrelevant observations, quoted data and
receipts. Later distractors must not genuinely supersede the deciding event.
The criterion names the event/request whose outcome is being judged, and
explicitly requires its deciding response/tool evidence. Its absence is
inconclusive. Expected reference truth alone does not establish an action.
Wrong deciding evidence is fail; complete correct evidence is pass.

The secondary criterion must identify a particular receipt event. Later or
earlier distractor receipts use disjoint event IDs and plausible near tokens;
they cannot satisfy that criterion. A missing required token in an observed
receipt is fail, not inconclusive. Missing primary evidence is explicit while
unrelated tools and receipts remain visible. No case depends on hidden intent,
unstated policy or ambiguous chronology. No actor reuses a real identifier.

Create generator, hard.json, PREREGISTRATION.md and executable tests only under
longtrace/. Fixed seed 20261014. Generation must not inspect recorded model
outputs. Freeze all labels and record dataset/generator hashes. Explain each
family's oracle and assert deciding position, trace lengths, call counts,
receipt/token independence, IDs, label balance and all labels mechanically.
Test mutations that remove evidence, change a token or reorder deciding calls
must fail construction checks. Do not call models, edit any existing fixture,
frozen source, recording, page, ledger or report, commit, push, or use Azure.
You are not alone in the worktree. Other writers own all other paths. Never
revert their edits. Return a file pointer and measured construction results.
