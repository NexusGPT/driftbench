# Trusted event adapter v2 preregistration

The owner confirms an adapter defect after the frozen hard/fresh runs. The old adapter put the entire mixed-role receipt, user request and trace gap inside one agent entry. Published PR 115 criterion scores remain 119/120 and 59/60, with that defect disclosed. Every original recording, label, cost and prediction stays unchanged. Those criterion measurements do not isolate pure judge quality.

The replacement consumes explicit events emitted at fixture construction. It does not parse bracket tags into roles. A nested `[agent]` inside a context gap stays literal context text. Tools remain separate events in observed order. Reference scenario context remains separate from observed agent behavior. Default prompts and parsers are unchanged. All procedures receive the same event content; native receives trusted JSON event serialization inside its existing transcript wrapper. Production package sources are untouched.

Short validation: new seed 20261019, 120 cases, original generator families and oracle, primary 48 pass / 48 fail / 24 inconclusive, independent receipt 60 pass / 60 fail. The explicit events are generated from construction variables, and all legacy fields exactly match the original generator at that seed. Zero complete-input overlap with prior hard/fresh and the unused seed 20261018 cohort. The new set is untouched validation; no new outcomes can tune a procedure.

Long validation: new seed 20261020, 120 cases, longer traces with deciding evidence early, multiple tools and distractor receipts. The full construction/oracle/mutation contract is in longtrace-v2/PREREGISTRATION.md. This is a separately reported harder cohort, not a replacement for the short validation.

Every contestant runs once on each new cohort: old main shipped default, original audit candidate, native default, conformance candidate, PR 115 default at 8195902dd20c84267f85feba268c17868e00dfbe. Both candidates are **not yet the shipped default**. There is no valid-answer retry, outcome selection, fresh tuning or label change. An empty native structured CLI call gets one identical-input six-turn transport recovery; failed recovery is unscored for that contestant with coverage named.

Preregistered primary measurement: all 240 individual criteria. Secondary views: 120 primary-case verdicts, 120 receipt verdicts and 120 complete vectors. Publish every procedure and every loss, Wilson intervals, confusion matrices, family counts and costs. Shared families are correlated, so intervals are descriptive. Historical short hard/fresh results are shown beside corrected new-seed results with adapter versions explicit.

The source, labels, generator, tests, protocols and SHA-256 manifest are committed before any model call. Runtime refuses uncommitted or changed frozen bytes. Records carry the registration commit, fixture hash, procedure hash manifest and PR 115 source/runtime provenance. Model calls remain serial through the existing Haiku CLI with the cumulative 8 USD task cap and 07:00 Brussels deadline.

The old conformance seed 20261018 and old long seed 20261014 constructions were never measured. They remain as superseded, unmeasured artifacts. Their known-defective role framing is not run after this correction. The conformance procedure itself remains frozen; only the shared event adapter changes.
