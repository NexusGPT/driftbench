## Optional post-run canonical formatting

The original no-migration path remains strict. A present
`final-format-migration.json` is accepted only after all ten v2 raw records and
all 40 metric rows are complete. Its `originalFreeze` must equal the archived
`pre-final-format/adapter-v2-freeze.json.txt`. Every listed change requires exact
archival original bytes, an original freeze digest, a canonical current digest,
a supported artifact kind and `semanticEqual: true`. Unlisted frozen artifacts
must retain their original hashes. Updated current freeze hashes may differ only
at certified paths and require a `storageFormatting` annotation.

JSON fixtures are independently compared deeply, including labels and literal
entry values. TypeScript sources are independently parsed with the repository's
TypeScript package; significant tokens and structural ASTs must agree. This
rejects behavior changes such as automatic-semicolon-insertion drift, even when
ordinary token sequences agree. Whitespace and comment trivia do not affect the
comparison. Only a comma immediately before a closing brace or bracket is
normalized, and the structural AST must still agree. Array holes/elisions,
operators, identifiers, literals and every other significant token remain
protected. A function-argument trailing comma before a closing parenthesis is
not normalized.

`unchangedModelInputs: true` and an exact `verifiedRequestCount` are mandatory.
That count includes every `request_sha256s` reference across the ten v2 records,
including repeated references. The root's independent verifier reconstitutes
all current model inputs against their original recordings. The report guard
checks this certificate and retains all original recorded procedure/fixture
hashes. Original committed freeze, fixture and adapter snapshots are still
verified at each recorded registration commit; canonical hashes do not replace
the measurement stamps.
