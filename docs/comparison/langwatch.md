# LangWatch: comparison

LangWatch is an evaluation platform whose evaluators (the langevals package) cover checks, judges and metrics. Its Scenario SDK runs simulated users against an agent and judges the conversation. This page reads the evaluators at commit e683dd9e and the Scenario SDK at commit ad220e6a, as the source records them.

Results come from the comparison table. Limit means a row is not being worked, with its reason stated.

## Not compared

- LangWatch's prompt-injection classifiers (Azure jailbreak, prompt injection, OpenAI moderation): not run, because they call an external service.
- LangWatch's cache key on a live run: read only, because a run needs their scenario runtime and a model.
- LangWatch's trace-span anchors and annotation interface: not run here, and our stored runs carry no trace spans.
- Retrieval metrics (faithfulness, context precision and recall): we do not build them, so there is no like-for-like case.
