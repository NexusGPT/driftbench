# LangWatch: comparison

LangWatch is an LLM evaluation platform with a catalogue of evaluators (langevals). Scenario is its SDK for simulated users that drive an agent through a conversation and judge the result. The commits read in the source are e683dd9e (evaluators) and ad220e6a (Scenario).

Results come from the comparison table. Limit means a row is not being worked, with its reason stated.

## Not compared

- LangWatch's injection classifiers (Azure jailbreak, prompt injection, OpenAI moderation) need provider keys, so they were not run.
- Retrieval metrics (faithfulness, context precision and recall) have no counterpart here, because our blocks carry no retrieved contexts.
- The judge decision phase has no counterpart here, because driftbench blocks are fixed.
- Live trace import into a run was not measured. Only the OpenTelemetry fixture was tested.
- No run of LangWatch's cache view was measured. The Scenario cache module cited for the caching row is not in the clone, so only its key-value client was read.
- LangWatch's annotation queue interface was not compared, because it has no run here.
