# LangWatch: comparison

LangWatch is an evaluation platform. Its evaluators (langevals) cover checks, judges and metrics, and its Scenario SDK runs a simulated user against an agent and judges the conversation. This page compares driftbench with both. The source read for this page is commit e683dd9e for the evaluators and commit ad220e6a for Scenario.

Results come from the comparison table. Limit means a row is not being worked, with its reason stated.

## Not compared

- LangWatch's prompt-injection classifiers (Azure jailbreak, prompt injection, OpenAI moderation): not run, because they call an external service that was not available here.
- LangWatch's annotation interface: no run here, so the interface is not compared.
- Scenario's caching on a live run: read from source only, because a run needs its scenario runtime and a model.
- LangWatch's trace-span annotation anchors: driftbench stored runs carry no trace spans, so the span form cannot be matched on the same input.
- Retrieval metrics (faithfulness, context precision and recall): driftbench blocks carry no retrieved contexts, so there is no like-for-like case.
- Scenario's judge decision step: driftbench blocks are fixed, so there is no per-turn decision to compare.
