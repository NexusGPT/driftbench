# Langfuse: comparison

Langfuse is a platform for tracing, evaluating and managing LLM applications. Every Langfuse comparison was made against its public documentation (docs read 2026-10-12, source commit cb2cebae). No Langfuse instance was run.

Results come from the comparison table. Limit means a row is not being worked, with its reason stated.
