# Langfuse: comparison

Langfuse is a platform for tracing, evaluating and managing LLM applications. Every Langfuse comparison here was made against its public documentation (docs read 2026-10-12, source commit cb2cebae as the source records it). No Langfuse instance was run.

## Not compared

- No Langfuse instance was run, so no row is a measured head-to-head.
- Their source code was not read. The comparisons use their public documentation only.
- Prompt labels such as `production`: their docs name labels in a caption only, so no behaviour was compared.
- Linkage from prompts to traces and experiments: no documented behaviour was found.
- Dataset item fields, dataset versioning, run comparison and judge model choice: reviewed from their docs only, not measured.
- Claude Code sessions: their docs cover no Claude Code session, so none was compared.
