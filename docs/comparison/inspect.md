# Inspect: comparison

Inspect (inspect_ai) is a framework for running and scoring language model evaluations, with scorers, reducers, sandboxes and an eval log. This page compares driftbench with inspect_ai 0.3.278 at commit a1dbea8, as the source records them. Each row states what was measured, what was read in the code or docs, and what is still open.

| Capability | Result | Basis | Example | Reproduce |
|---|---|---|---|---|
| Judge prompt: fail-first rubric with a data-tag guard, against a closed-question template | ahead | measured head-to-head | sheet_matches_catalog: their format gave the wrong verdict on 2 of 3 repeats of the fail fixture and 1 of 3 of the pass fixture. Ours gave the right verdict on all six. Over 72 calls per side, with the same model (haiku, through the claude command), rubric and transcript: ours 71 of 71 scored answers right and 1 inconclusive; theirs 69 of 72 right and 3 wrong. Spend 0.0120 and 0.0279 USD. | `npx tsx comparisons/inspect/grader-prompt/grader-probe.mts ours <output path>`, and the same with `theirs`. Needs the claude command. |

## Not compared

- Inspect's log viewer, and per-model-call timestamps in its event log.
- Inspect's eval log field by field. The run record was compared, not the whole log.
- Inspect's event log and sandbox cleanup on a killed run. Those cases were not run.
- Inspect's container enforcement. No docker host was available.
- Inspect's three-model borderline council. Opus answers were not recorded within budget.
- Resume of an interrupted sample. Inspect's resume is not compared; ours is not built.
- Fact-check accuracy on sets other than the hard, easy and multi-part sets.
- Inspect's workspace snapshot walk. None was found in its code.
