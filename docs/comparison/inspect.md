# Inspect: comparison

Inspect (inspect_ai) is a framework for evaluating language model applications. This page compares driftbench with inspect_ai version 0.3.278, read in its source at commit a1dbea8.

Results come from the comparison table. Limit means a row is not being worked, with its reason stated.

## Not compared

- Eval log format field for field. Inspect has per-model-call start times and a viewer, which ours does not have yet.
- A killed run's log. Inspect was not run on killed runs, so no killed-run comparison exists.
- Container network enforcement. This host has no docker, so the flag was checked, not the enforcement.
- Approval before the call for self-running runtimes. Inspect's gate covers only the tools it defines, so there is no like-for-like run.
- Workspace walk bounds. Read from the source only; no snapshot was run on either side.
