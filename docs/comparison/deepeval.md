# DeepEval: comparison

DeepEval (confident-ai/deepeval) is an open Python library that scores LLM replies with judge-model metrics and a few deterministic checks. This page reads its source at commit 4598fe8. The re-measurement used generated cases with a fixed seed (20261012), and the judges were the claude command on haiku and sonnet.

Results come from the comparison table. Limit means a row is not being worked, with its reason stated.

## Not compared

- G-Eval non-strict mode: it needs model log-probabilities, which the claude command cannot return.
- DeepEval's default OpenAI judge model: the DeepEval prompts ran on the claude command instead.
- DeepEval's threshold tuning: its own default threshold (0.5) was used, not a tuned value.
- Real customer wording: the cases are generated from templates, so the results test known shapes only.
