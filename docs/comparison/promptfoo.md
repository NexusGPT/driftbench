# promptfoo: comparison

promptfoo is an open-source framework for testing LLM applications, with assertions, red-team plugins and simulated users. This page is based on its source at commit 8014282. Some rows are measured on the same inputs or on generated cases with a fixed seed, and the rest are compared by reading its code or docs.

Results come from the comparison table. Limit means a row is not being worked, with its reason stated.

## Not compared

- ROUGE, BLEU, METEOR, GLEU and n-grams: skipped here, the metrics are built elsewhere.
- Perplexity: needs token log probabilities, which our adapter contract does not carry.
- Trace span checks: theirs use OpenTelemetry spans, and our adapters record calls.
- RAG faithfulness, recall and relevance: Max has no retrieval step.
- Classifier, moderation, pi and webhook checks: not built.
- Red-team prompt extraction: not measured.
- Goal success with the trace: the judges read only the reply, and their judge with the trace was not run.
