How the numbers are made

  • Every interval is two-sided at 95%.
  • Wilson: the score interval on k of n, used for a rate over independent units (the repeats of one golden, the goldens of a campaign).
  • Cluster bootstrap: 2000 percentile resamples of whole clusters, seed 1, so the same store gives the same page. Anything pooled over blocks takes one run (one conversation) as one cluster; anything pooled over the runs of a mode takes one golden as one cluster.
  • Wilson over clusters: a pass rate whose values all agree (every block passes, or none does) leaves a bootstrap no width, so it takes the Wilson interval with each cluster counted once.
  • Newcombe: the paired difference of two rates, for baseline against candidate.
  • No interval: a bootstrap over a single cluster has none; the page says so instead of drawing one.
  • A run passes when it completes, every block passes and the end state matches.
