# Warranty and returns

A warranty case covers a fault in a part or in the work. It does not cover wear.

## Cover periods

The cover period is 24 months. A claim on a cracked frame must be made within the period in the sentence before this one.

Workmanship is covered for 90 days after the repair. We refuse the return of a tyre that has been fitted. Ms Okonkwo signed the warranty terms in 2019.

## Return windows

| Item | Return window |
|---|---|
| Helmet | Within 28 days |
| Lights and bells | Within 30 days |
| Saddle | Within 14 days |

## Handling a case

Ask the rider for between 2 and 5 photos of the fault. If a rider writes twice about one case, ask the shop manager to call them.

## Examples

A message such as "The fork on my gravel bike creaked after 3 weeks" is a warranty claim. Open a case and ask for photos.

Last year the shops handled 187 claims.
