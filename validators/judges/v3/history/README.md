# Superseded measurements

These records run the completed scorer from round zero. They establish
repeatability only and do not measure a repair climb. They are retained as
history, excluded from the current journal and hardness forecast. The
[stub-start protocol](../PILOT.md) replaces this experiment.

The `two-repair-stub/` directory records the subsequent genuine 300-item climb,
which stops after two repairs when the owner requests statistical extensions.
It is also excluded from the expanded journal. Historical Markdown links are
adjusted to their archived targets; numerical results and verdicts are preserved.

The `broad-batch-excluded/` directory retains an expanded-bank experiment that
bundles all fourteen APIs into one repair. Both executors reach 334/334, but
that sequence violates the one-cause-per-round protocol. Fresh executors replace
it; these results also contribute nothing to the current forecast.
